# KSA 라벨 출력 시스템 v4 — PC·모바일 공용 웹앱

이 버전은 기존 단일 HTML 기능을 유지하면서 저장 계층을 Supabase로 확장한 버전입니다.

## 핵심 동작

- PC와 휴대폰이 같은 URL로 접속합니다.
- 제품관리(마스터), 작업지시, 라벨 서식 데이터를 Supabase에 저장합니다.
- 한 기기에서 수정하면 다른 기기에서도 같은 데이터를 읽습니다.
- Supabase 설정이 없으면 자동으로 브라우저 localStorage 모드로 동작합니다.
- 모바일 관리자 버튼/PIN UI와 반응형 화면을 포함합니다.
- 라벨 출력은 브라우저가 연결된 프린터를 통해 진행합니다.

## 1. Supabase 만들기

1. https://supabase.com 에서 프로젝트를 하나 만듭니다.
2. SQL Editor에서 `supabase.sql` 전체를 실행합니다.
3. Project Settings → API에서 다음 두 값을 확인합니다.
   - Project URL
   - anon public key

## 2. config.js 수정

`config.js`를 열고 아래 두 값을 바꿉니다.

```js
window.KSA_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "여기에 anon key"
};
```

## 3. 웹에 올리기

아래 중 하나로 `index.html`, `config.js`를 같은 폴더에 올리면 됩니다.

- Netlify
- Vercel
- GitHub Pages
- 사내 웹서버

정적 파일만 올려도 동작합니다.

## 4. 모바일 사용

배포된 주소를 Chrome/Safari로 열면 됩니다.
홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

예:
`https://ksa-label.example.com`

## 데이터 구조

현재 기존 앱의 저장 키를 그대로 공유합니다.

- 라벨 서식
- 작업지시
- 사용자 등록 제품마스터

따라서 기존 UI를 크게 바꾸지 않고 공유 DB만 연결했습니다.

## 관리자 PIN

현재 PIN은 기존 코드의 `1234`입니다.

중요: 이 PIN은 화면 UI 잠금 용도입니다. 보안이 필요한 실제 사내 배포에서는
Supabase Auth나 사내 로그인과 연결하는 것을 권장합니다.

## 프린터 관련

브라우저 보안상 웹페이지가 사용자 확인 없이 프린터로 바로 출력하는 것은 제한됩니다.
라벨 프린터가 연결된 PC/태블릿에서 브라우저 인쇄창을 통해 출력하는 방식입니다.

모바일은 작업지시 확인/등록/마스터 관리용으로 사용하고,
실제 산업용 라벨 프린터는 PC 또는 프린터가 연결된 태블릿에서 출력하는 구성이 가장 안정적입니다.

## v4.13.0 변경사항

- 제품마스터를 `품목코드 + 품목명(ECOUNT 풀네임) + 약어(라벨용)` 구조로 분리했습니다.
- 제품 검색은 품목코드와 ECOUNT 풀네임만 사용하며, 약어는 라벨 출력용으로만 사용합니다.
- 제품별 선택형 바코드 정보를 추가했습니다: 바코드 값, 종류(CODE128/EAN-13/CODE39/ITF-14/CODABAR), 숫자 표시/숨김.
- 라벨 서식 편집기의 변수에 `바코드 이미지`, `바코드 숫자`, `ECOUNT 품목명`, `라벨 약어`를 추가했습니다.
- 바코드 값이 비어 있는 제품은 바코드/바코드 숫자가 출력되지 않습니다.
- 라벨에 삽입하는 일반 텍스트/변수 항목은 `텍스트 배경 투명`이 기본값이며, 필요하면 흰색 배경으로 전환할 수 있습니다.
- Excel 제품마스터 업로드/내보내기 양식에도 ECOUNT 품목명, 약어, 바코드 관련 열을 반영했습니다.

### 바코드 라벨에 배치하기

라벨 마스터 → 서식 편집에서 `변수` 항목을 추가한 뒤 다음 변수를 선택합니다.

- `바코드 이미지`: 제품마스터의 바코드 값을 실제 바코드로 표시
- `바코드 숫자(표시 설정 적용)`: 제품마스터에서 숫자를 `표시`한 품목만 숫자를 표시

두 항목을 위/아래로 배치하면 일반적인 `바코드 + 하단 숫자` 형태가 됩니다. 숫자를 `숨김`으로 설정한 품목은 같은 서식을 사용해도 하단 숫자만 자동으로 비워집니다.

## v4.20 변경사항 (노루알엔씨 두 날짜 관리 + 대량 출력 안정화)

### 실제 제조일 / 재고생성일 분리 관리
- 실제 제조일 = 작업지시 생산일자 → `*YY00...` LOT 계산 기준 (기존과 동일)
- 재고생성일 = 라벨의 `제조일:` 및 `NDYYMMDD01~` 시리얼 기준 (노루알엔씨 화면에서 지정)
- 재고생성일을 **작업지시별로 저장**합니다 (작업지시를 다시 선택하면 복원, 출력 성공 시 확정 기록).
- 노루 패널 미리보기에 두 날짜를 나란히 표시합니다.
- 출력 이력/CSV에 **실제 제조일**, **재고생성일** 열을 추가했습니다.
- 라벨 생성 후 재고생성일·시리얼 설정이 바뀌면 옛 라벨 출력을 막고 재생성을 안내합니다.

### 100장 이상 출력 시 느림/끊김 수정
- 변환(렌더→ZPL)과 전송을 병행 (기존: 전부 변환 후 마지막에 한 번에 전송 → 변환 중 연결 유휴/끊김)
- 전송 묶음 1.75MB → 약 600KB/30장, 묶음당 45초 타임아웃, 실패 시 프린터 재탐색 후 최대 3회 시도
- 라벨마다 이벤트 루프 양보 + 캔버스 즉시 해제, 동일 내용 라벨은 변환 결과 재사용
- 자동 모드에서 일부 출력 후 실패 시 브라우저 인쇄로 전체가 **중복 출력되던 문제** 수정
- 출력 이력 저장 실패가 "출력 실패"로 오인되던 문제 수정
- 중간 실패 시 "N장 전송됨, N+1번째부터 이어서 출력" 안내

## v4.21 변경사항 (ND 시리얼 / LOT 중복 방지)
- 이미 출력된 ND 시리얼(품목 무관)이 있으면 출력 전 경고 → 확인해야만 재출력, 취소 시 연번 보정 자동 제안
- 같은 품목·LOT·드럼번호로 이미 출력된 라벨도 경고 (LOT 하나를 여러 드럼이 공유하는 것은 정상)
- 이번 출력 안에서 같은 시리얼이 2번 나오면 무조건 차단
- 출력 중 버튼 중복 클릭 방지, 실제 전송된 라벨만 등록, 테스트/계획 없이 출력은 검사 제외
- 기존 출력 이력의 시리얼도 함께 검사, 기록은 400일 보관

## v4.22 변경사항
- 프린터 설정의 안내 설명 박스 삭제 → 같은 자리에 **출력 이력 조회**(출력일 · 로트번호 · ND번호 1:1 매칭, 출력일/검색어 필터, 중복 ND 표시, CSV 저장)
- 노루 모드 작업지시 **중복 등록 방지**: 같은 품목코드 + 같은 LOT 의 작업지시는 직접 등록/Excel 반영에서 제외되고 사유 표시
- 작업지시 목록에서 이미 중복된 건에 "LOT 중복" 배지 표시

## v4.23 변경사항
- "노루알엔씨 라벨" 버튼/제목/권한 메뉴 이름을 **출고 라벨 프린트**로 변경
- 출고 라벨 프린트 화면에서는 **관리자가 아니어도 작업지시(계획) 삭제 가능** (카드 삭제 + 선택 삭제, 삭제 전 확인창). 수정 버튼은 관리자만.
- 출고 라벨 출력이력은 **출고 라벨 프린트 화면에서만** 표시 (일반 출력이력/프린터 설정 이력 조회에서는 제외, 출고 화면에는 이력 패널이 자동 표시)
- LOT 직접입력({INPUT3}) 라벨: **품목코드별 마지막 입력값을 기억**하고 직접 등록 폼 · 수정창 · 출력 시 입력창에 자동으로 채움 (언제든 수정 가능, 직접 고친 값은 덮어쓰지 않음)

## v4.24 변경사항 (프레스일지 화면 · 엑셀 열 너비)
- 프레스일지 화면: 최대폭(1180px) 제한 제거, 표는 항상 **화면 폭 100%**를 채움(가로 스크롤 없음). 휴대폰(≤700px)·태블릿(≤900px)은 글자/여백을 줄여 한 화면에 모두 표시.
- 화면에서 끌어 조절한 열 너비는 **비율**로 저장·적용되어 어떤 화면 크기에서도 꽉 차게 유지됨 (끌 때 커서를 정확히 따라감).
- 엑셀 내보내기 열 너비: (원인) 화면에서 열 너비를 한 번이라도 조절하면 px÷7로 계산돼 입력칸이 급격히 좁아지던 문제 수정.
  내용(한글=2칸)이 잘리지 않는 최소 너비 + 화면 조절 비율 반영 + A4 가로 한 페이지 폭(합계 ≈146)을 채우도록 확대, 입력칸 6개는 같은 너비(최소 12).
- 엑셀 인쇄 설정: A4 가로, 한 페이지 폭 맞춤, 좁은 여백(좌우 0.25"), 가운데 정렬.

## v4.25 변경사항
- 중복 경고에서 [취소]할 때 **연번 보정을 자동으로 올려 주자고 제안하던 기능을 삭제**했습니다. 시리얼 연번은 드럼 번호 + 사용자가 직접 입력한 '연번 보정' 값으로만 계산됩니다.

## v4.26 변경사항 (개월 수 변수 + 출력 시 개월 수 지정)
- 출력 화면(일괄/실시간) 위에 **개월 수** 입력칸 추가 — **숫자만 입력 가능**(1~120, 최대 3자리, 붙여넣기도 숫자만 남김).
- 작업지시를 선택하면 제품 사용기한(일)÷30 값이 자동으로 채워지고, 직접 바꾸면 미리보기·출력에 바로 반영됩니다. 이미 생성한 라벨도 출력 직전에 현재 입력값으로 갱신됩니다.
- 라벨 서식 변수 추가: **개월 수**(3) / **개월 수 + 개월**(3개월) / **제조일로부터 N개월** / **[제조일로부터 N개월]**(대괄호 포함)
