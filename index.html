🏷라벨 마스터 · 신규 / 수정 / 삭제

라벨코드는 자동으로 채번됩니다. 라벨명·기본 출력 장수·사용 여부를 관리하고, 서식 편집에서 라벨 디자인을 직접 편집합니다.
선택한 기존 라벨의 서식만 복사합니다. 캔버스·블록·Table·글꼴·위치·회전·변수 연결은 복제되며, LOT 체계·제품 연결·라벨명은 복사하지 않습니다.
제품에서 이 라벨을 선택하면 이 LOT 체계를 우선 적용합니다. 미지정 시 제품 기본 LOT 규칙을 사용합니다.

▦제품관리 (마스터)

예: LOT 123, 고정값 RSSL0164 → '0' + {LOT} + {BARCODE_FIXED} = 0123RSSL0164
사용 가능: {LOT}, {LOT_PAD2}, {LOT_PAD3}, {LOT_PAD4}, {ITEM_CODE}, {ITEM_NAME}, {ALIAS}, {BARCODE_FIXED}, {PROD_YYYYMMDD}, {PROD_YYMMDD}
검색과 ECOUNT 연동 기준은 품목코드 + 품목명(ECOUNT 풀네임)입니다. 약어는 라벨에 표시하기 위한 전용 값입니다.
바코드는 필요한 품목만 입력하고, 숫자 표시/숨김을 품목별로 선택할 수 있습니다. 규칙식으로 고정 텍스트 + LOT/품목/생산일자 변수를 조합할 수 있습니다. 내부 연결은 이름이 아닌 고유 Master ID를 사용합니다.

🏷이 제품에 사용할 라벨 선택 0개 선택

라벨 자체·서식·기본 LOT 체계는 라벨 마스터·서식에서 관리합니다. 여기서는 이 제품에 사용할 라벨만 선택합니다. 여러 개를 동시에 선택할 수 있고, 출력할 때 선택한 라벨의 LOT 체계가 자동 적용됩니다.
